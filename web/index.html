Folaio Plus Optional

A tiny brain that adds a short "In simple words" explanation under each answer and writes extra summaries. Downloaded once, then it works offline. You can switch it off or remove it any time.

One more step to use Folaio Plus. The engine that runs Plus brains isn't installed yet. Stop Folaio, then run the command for your computer in the Folaio folder (see the README for details):
Mac / Linux: .venv/bin/pip install -r requirements-plus.txt
Windows: .venv\Scripts\pip install llama-cpp-python --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu
